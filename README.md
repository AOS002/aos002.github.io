# Ashwin Sudhir — Personal Website

Personal academic website: https://aos002.github.io/

Built with HTML, CSS, and JavaScript. GitHub Pages publishes the `main` branch from the repository root.

- Edit `index.html` for content.
- Edit `styles.css` for appearance.
- Edit `script.js` for navigation and the footer year.
- Replace `assets/ashwin-sudhir-cv.pdf` to update the downloadable CV.

The CSS, JavaScript, and CV PDF URLs in `index.html` use the first 12 characters of each file's SHA-256 hash as a `?v=` parameter. Refresh the matching parameter when changing a file so browsers load the current assets. Keep the public CV free of the mobile number.

To preview locally, run `python3 -m http.server 8000` and open http://localhost:8000.
